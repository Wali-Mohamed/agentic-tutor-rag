# agentic-tutor-rag
An Agentic RAG virtual assistant for GCSE math tutoring, featuring tool calling, evaluation, and monitoring. Built for LLM Zoomcamp 2026.

A production-ready Agentic RAG system built to automate inquiries, pricing calculations, and scheduling for a private GCSE math tutoring business. Developed as a final project for the LLM Zoomcamp 2026, this repository demonstrates advanced retrieval techniques, LLM tool routing, automated evaluation metrics, and system monitoring.
